# 个人特色 IP 产品方案（v6 · 笔记本即 IP）

> **相对 v5 的核心变化**  
> - **取消**知识库二级「个人特色 IP」独立区（`/notes/author-ip` 降级为兼容跳转，见 §8）。  
> - **笔记本 = IP**：每个用户笔记本可绑定一条 `author_ips`，资料留在该本内。  
> - **只蒸馏当前勾选资料**（与「向资料提问 / 生成文章 / 发布自媒体」共用 `draftSelectedNoteIds`）。  
> - **入口**：参考资料区「+ 添加资料」右侧 **「生成我的 IP」** → **简洁弹窗**（不含写作能力）。  
> - **风格消费**：写入播客人设、生成文章、自媒体写作人设（见 §六）。  
> - **资料变更**：不自动蒸馏，快照对比标 **待更新**（见 §五）。  
> - **体验优化（v6.1）**：缩短路径、弹窗降为详情、勾选即参与风格、下游默认本笔记本风格（见 §十三）。  
>
> **延续 v5 已定稿**（未重复展开）：计费有余额即用、默认「我的 IP」不可删可改名、回收站双 Tab、复制 IP 深拷贝等——见 [author-ip-product-v5.md](./author-ip-product-v5.md)。

---

## 一、产品目标

| 目标 | 说明 |
|------|------|
| 统一心智 | 用户在**放资料的笔记本**完成：勾选 → 生成 IP → 在播客/文章/自媒体中使用 |
| 范围清晰 | 仅 **当前笔记本 + 当前勾选 note** 参与蒸馏，避免全库误学 |
| 一处生成、多处消费 | 本笔记本生成一次风格包，下游默认选用，可选手动覆盖 |
| 界面极简 | 弹窗只做风格状态与更新，写作留在笔记本底部既有入口 |
| 路径最短 | 主操作尽量 **一键完成**；弹窗用于查看详情，非必经（见 §十三） |

**一句话**：知识库是资料仓；笔记本上的「我的 IP」是从勾选资料蒸馏出的**写作人设包**，供全站创作链路引用。用户侧统一称 **「写作风格」**，少用 IP/蒸馏等术语。

## 二、信息架构

### 2.1 导航

```text
知识库 /notes
  └─ 笔记本 {name}
        ├─ 参考资料（勾选 draftSelectedNoteIds）
        ├─ [ + 添加资料 ]  [ 生成我的 IP ]
        ├─ 底部：提问 · 音频概览 · 生成文章 · 发布到自媒体
        └─ 「生成我的 IP」→ 风格弹窗（非独立路由）

回收站 /notes/trash
  └─ Tab：参考资料 | 个人特色 IP（延续 v5）
```

| 变更 | 行为 |
|------|------|
| 侧栏 | **移除**二级「我的风格IP / 个人特色 IP」 |
| 隐藏本 | 系统本 `__author_ip:*` 不出现在笔记本列表 |
| 旧路由 | `/notes/author-ip/*` 保留 1～2 版本 301/提示，跳转默认笔记本或对应绑定本 |

### 2.2 对象关系

| 实体 | 规则 |
|------|------|
| 笔记本 | 用户可见资料容器 |
| IP | 与笔记本 **1:1**（`author_ips.notebook_name` = 用户笔记本名） |
| 风格素材 | 普通 note，存于该笔记本；元数据标记是否参与学习 |
| 勾选集 | `draftSelectedNoteIds` = 提问 / 成稿 / 自媒体 / **生成·更新 IP** 的唯一来源 |

**参与学习的 note（蒸馏输入）须同时满足：**

1. 属于当前 `selectedNotebook`；  
2. `noteId ∈ draftSelectedNoteIds`；  
3. **勾选即参与风格**（v6.1）：与 `draftSelectedNoteIds` 同步，**不单独暴露**「参与风格学习」开关；取消勾选视为移出风格池；  
4. 正文可解析（长度 > 0，与现网 `canUpdateAuthorIpStyle` 一致）。  

learn 成功后，列表行可展示轻标签 `已纳入风格`（仅提示，非第二套勾选）。

### 2.3 懒创建 IP

| 时机 | 行为 |
|------|------|
| 用户在某笔记本首次点击「生成我的 IP」 | `POST .../by-notebook/{notebookName}/ensure` 创建/返回 IP |
| 注册 / 首次进知识库 | 可仅为「默认笔记本」ensure，**不**再强制独立 IP 列表页 |

## 三、入口与「生成我的 IP」弹窗

### 3.1 按钮位置与状态（v6.1）

位于参考资料区，**「+ 添加资料」右侧**（同一行或紧邻）。**不在**底部创作区重复增加「风格」入口。

```text
[ + 添加资料 ]    [ 提炼我的写作风格 ]  → 已有风格时变为状态芯片
```

| 状态 | 控件 | 点击行为（v6.1 主路径） |
|------|------|-------------------------|
| 未选笔记本 | disabled | — |
| 勾选 0 条 | disabled | 「请先勾选资料」 |
| **未生成** + 可学习 | 主按钮 `提炼我的写作风格` | **直接 learn**（一键），成功 toast；「查看风格」进弹窗 |
| **已就绪** | 芯片 `风格已就绪 ▾` | 下拉：查看详情 / 更新风格 / 补充定位（可选） |
| **待更新** | 芯片 `待更新 ▾` 或主按钮 `更新风格 (N条)` | **一键 learn**；顶栏一行轻提示（见 §十三.5） |
| 分享只读本 | disabled | — |

> 对外文案统一 **「写作风格」**；内部实体仍为 `author_ip`。首次用「提炼…」，之后用「更新风格」。

### 3.2 弹窗定位

- **类型**：居中单弹窗（约 `max-w-md`），非全屏工作台、非右侧大抽屉。  
- **职责（v6.1）**：**详情与管理**（查看状态、折叠详情、补充定位、手动更新）；**非必经**——主路径在工具栏一键完成。  
- **明确不含**：写一篇、主题输入、跳转写作页、大段「添加素材」引导；弹窗内**不重复**资料标题列表（仅「已选 N 条，与左侧一致」）。

### 3.3 弹窗线框

```text
┌─────────────────────────────────────┐
│ 我的 IP · {笔记本名}            [×] │
├─────────────────────────────────────┤
│ ● 未生成 | 已就绪 | 待更新          │
│ 基于已选 N 条 · 上次更新 M/D HH:mm  │
│ 一句话摘要 + 最多 5 个 chip         │
├─────────────────────────────────────┤
│ ▼ 查看详情（默认折叠）              │
│   · 特色列表（维度 + label）        │
│   · 最近变像一句（recentChange）    │
│   · 辐射图（可选，默认不展示）      │
├─────────────────────────────────────┤
│ 已选 N 条资料（与左侧勾选一致）       │
├─────────────────────────────────────┤
│ [ 更新风格 ]（弹窗内，可选）          │
│ 补充定位（可选，链接）              │
└─────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| 辐射图 | **默认不展示**，放入「查看详情」折叠 |
| 主按钮 | 工具栏一键为主；弹窗内「更新风格」与工具栏同逻辑 |
| 编辑定位 | 嵌套小弹窗；**非首次阻塞**；learn 后可补 |
| 成功反馈 | Toast 一句：「风格已更新，已用于播客、文章与自媒体」；**不再**叠第二层说明弹窗 |

### 3.4 与列表勾选的关系

- 勾选仅在左侧列表修改；弹窗/芯片只展示 **「已选 N 条」**。  
- 改勾选后若与快照不一致 → `待更新`（§五）；工具栏可一键更新。

## 四、蒸馏（生成 / 更新风格）

### 4.1 触发

- **仅**用户点击弹窗主按钮触发 `learn`（full 模式）。  
- **不**在保存 note、改勾选、导入资料时自动 learn。

### 4.2 请求范围

```http
POST /api/v1/author-ips/{ipId}/learn
{
  "mode": "full",
  "noteIds": ["uuid1", "uuid2"]   // 必填，均属该 IP 绑定笔记本
}
```

后端仅读取上述 noteIds 对应正文参与 LLM 蒸馏（traits / tagCloud / domains / recentChange），写入 `profile_json`。

### 4.3 输出（风格包）

| 字段 | 用途 |
|------|------|
| `traits[]` | 口吻、结构、禁区等 |
| `vitality.tagCloud` | 摘要 chips |
| `domains[]` | 场景 |
| `oneLiner` + `coldStart` | 定位 |
| `styleSnapshot` | 见 §五 |

### 4.4 用户态三态（UI）

| 展示 | 条件 |
|------|------|
| **未生成** | 无成功 learn 记录 / 无 `styleSnapshot` |
| **已就绪** | 有快照且 `styleSyncStatus !== outdated` |
| **待更新** | 快照与当前勾选+资料版本不一致（§五） |

> UI 使用 `styleSyncStatus`（`none` \| `ready` \| `outdated`），与后端 `maturity`（empty/sketch/ready）解耦展示。

## 五、资料变更与「待更新」

### 5.1 原则

**不自动全量蒸馏**；资料变化后标 **待更新**，由用户点「更新风格」再 learn。创作链路**暂用上次成功风格**，并轻提示。

### 5.2 快照（每次 learn 成功后写入）

```json
{
  "styleSnapshot": {
    "noteIds": ["id1", "id2"],
    "noteVersions": {
      "id1": "<contentHash 或 updatedAt>",
      "id2": "..."
    },
    "learnedAt": "2026-05-26T12:00:00Z"
  },
  "styleSyncStatus": "ready"
}
```

前端用 **当前 `draftSelectedNoteIds` + 各 note 版本** 与快照对比。

### 5.3 事件 → 行为

| 事件 | 是否 outdated | 说明 |
|------|:-------------:|------|
| 从未 learn | — | 未生成 |
| 勾选集与 `snapshot.noteIds` 不一致 | ✅ | 增删勾选即意图变更 |
| 快照内 note 正文变更 | ✅ | 保存、重新解析 |
| 快照内 note 删除 / 进回收站 | ✅ | 更新时剔除该 id |
| 取消「参与风格学习」 | ✅ | |
| 仅新增资料但未勾选 | ❌ | 仍已就绪 |
| 用户点击「更新风格」 | — | 用**当前勾选**重算，覆盖 profile + 快照，并同步下游人设 |

### 5.4 下游在 outdated 时

| 场景 | 行为 |
|------|------|
| 生成文章 / 自媒体 / 播客 | **允许**继续，使用**上次**风格包 |
| 提示 | 一行：「资料已变，建议更新风格后更准确」；可选在弹窗顶栏重复 |
| 更新成功后 | 写回三端人设（§六） |

### 5.5 不建议

| 方案 | 结论 |
|------|------|
| 每次保存 note 自动 learn | 否 |
| 每次改勾选自动 learn | 否 |
| 打开成稿前强制 learn | 否，仅提示 |

## 六、风格消费（三处写入）

统一规则：**默认使用当前笔记本已生成的 IP**；无 IP 时提示「请先生成我的 IP」。

### 6.1 播客 · 人设风格

| 项 | 说明 |
|----|------|
| 同步时机 | learn 成功后更新用户创意方案（如 `usr:notebook_{notebookKey}` 或绑定 `authorIpId`） |
| 内容 | traits + oneLiner + 代表性 tag → 播客人设摘要（speaker 口吻、节目调性） |
| 入口 | 笔记本「音频概览/播客」进工作室时，默认选中「本笔记本 IP」；芯片：`人设风格 · {笔记本名}` |
| 覆盖 | 用户可在工作室改选其他人设；以最后一次「更新风格」刷新默认项 |

### 6.2 生成文章

| 项 | 说明 |
|----|------|
| 新增 | **「本笔记本风格」**（v6.1 文案）：默认开启且 **折叠**，有人设时无需再选 |
| 注入 | `author_ip_id` + resolver 片段并入 `script_draft` prompt，或扩展 `script_style` |
| 资料 | 仍用 `draftSelectedNoteIds` 作 RAG；人设来自 IP，与资料同源笔记本 |
| 高级 | 折叠项「仅资料、不套风格」 |

### 6.3 发布到自媒体 · 写作人设

| 项 | 说明 |
|----|------|
| 新增 | 写作人设预设 **「本笔记本风格」**（置顶默认，v6.1） |
| 映射 | traits → `writerVoice` / `otherRequirements`；oneLiner → 口吻说明；tagCloud → 关键词 |
| 覆盖 | 选手工标签后视为覆盖；提供「恢复为本笔记本风格」 |

## 七、API 契约（产品层）

| 接口 | 说明 |
|------|------|
| `GET /author-ips/by-notebook/{notebookName}` | 取绑定 IP + `styleSyncStatus` + 摘要 |
| `POST /author-ips/by-notebook/{notebookName}/ensure` | 懒创建 1:1 IP |
| `POST /author-ips/{id}/learn` | body 必含 `noteIds[]` |
| `GET /author-ips/{id}` | 弹窗拉全量 profile |
| note metadata | `authorIpId`、`includeInStyleLearning`（笔记本内 note 可标所属 IP） |

**校验**：`noteIds` 必须全部属于该 IP 的 `notebook_name`；否则 400。

## 九、分阶段交付

| 阶段 | 交付 | 验收 |
|------|------|------|
| **M0** | 按钮 + 简洁弹窗；`ensure` + `learn(noteIds)`；`styleSnapshot` + outdated UI；隐藏二级导航 | 勾选 2 条 → 生成 → 摘要/chips 可见；改勾选 → 待更新 |

## 十、边界与规则

- **多笔记本 = 多套 IP**，互不串味。  
- **分享只读**：不可生成/更新 IP。  
- **示例/系统模板本**：只读，无「生成我的 IP」。  
- **计费**：`learn` 按既有 IP 用量扣费；主按钮旁可展示预检（与 v5 一致）。  
- **空勾选 / 不可解析**：按钮 disabled + 说明文案。

## 十一、成功指标（建议）

- 「生成我的 IP」点击率、learn 完成率  
- outdated → 更新风格 转化率  
- 成稿/自媒体/播客任务中带「本笔记本 IP」占比  
- 二级 IP 页 PV 下降、笔记本内停留时长上升

## 十二、与 v5 对照

| 维度 | v5 | v6 |
|------|----|----|
| 入口 | 二级 `/notes/author-ip` | 笔记本内按钮 + 弹窗 |
| 素材位置 | 隐藏本 `__author_ip:{id}` | 用户笔记本内 note |
| 蒸馏范围 | IP 本内可学习素材 | **仅当前勾选 noteIds** |
| 写作 | 独立写一篇路由 | **不在弹窗**；笔记本底部 + 人设选项 |

| 主路径（v6.1） | 常经独立 IP 页 + 弹窗确认 | **工具栏一键** + 弹窗仅详情 |

## 十三、体验优化（v6.1）

> **原则**：能力不减（勾选蒸馏、快照待更新、三端消费），**缩短路径、减少概念、符合知识库既有「勾选 = 本次所用资料」习惯**。

### 13.1 一条主路径（优先）

| 场景 | 优化前（v6.0） | v6.1 |
|------|----------------|------|
| 首次生成 | 勾选 → 开弹窗 → 再点生成 | 勾选 → **工具栏一键「提炼我的写作风格」** → toast |
| 已就绪 | 开弹窗查看 | **芯片「风格已就绪 ▾」**，下拉进详情 |
| 待更新 | 弹窗内更新 | **「更新风格 (N条)」一键** + 顶栏一行提示 |
| 查看详情 | 与生成同一弹窗 | 从芯片下拉或 toast 链入，**非必经** |

目标：完成 learn 的主路径 **≤2 次点击**（勾选不算）。

### 13.2 勾选 = 参与风格（单一心智）

- **取消**列表与预览中独立的「参与风格学习」开关（或仅保留后端字段，与勾选双向同步）。  
- 规则：**勾上 = 纳入本次风格池**；取消勾选 = 移出池；若曾在快照中则标 `outdated`。  
- learn 成功后行内轻标签 `已纳入风格`（可选），避免第二套概念。

与「向资料提问 / 生成文章 / 发布自媒体」共用 `draftSelectedNoteIds`，用户无需理解两套选择。

### 13.3 入口收敛

- 仅 **「+ 添加资料」右侧** 一个风格入口；已有风格时同一位置变为 **状态芯片**，避免双按钮。  
- 底部创作区 **不新增** 第四个「风格」按钮。  
- 从**本笔记本**进入播客工作室时，默认创意方案 = 本笔记本风格；全局 `/podcast` 入口才需手选。

### 13.4 弹窗再瘦身（功能保留）

| 保留 | 弱化 / 移除 |
|------|-------------|
| 状态三态、摘要、chips | 弹窗内重复资料标题列表 |
| 折叠「风格详情」（traits + recentChange） | 辐射图默认隐藏 |
| 弹窗内「更新风格」（与工具栏同逻辑） | 成功后的第二层说明弹窗 |
| 补充定位（可选链接） | 首次 learn 前强制定位向导 |

### 13.5 资料变更：少打扰、快修复

- **不拦截**生成文章 / 自媒体 / 播客（沿用 §5.4）。  
- 提醒仅两处：**芯片/按钮变黄** + **笔记本参考资料区顶栏一行**「资料已变，建议更新风格」。  
- 点「更新风格」默认当前勾选；勾选未变、仅正文变时，可提示「将用相同 N 条重新提炼」。  
- **不自动 learn**（避免惊吓扣费）。

### 13.6 下游默认带入（少选一个框）

| 链路 | v6.1 |
|------|------|
| 生成文章 | 有风格时默认 **「本笔记本风格」已开**，置于高级折叠 |

### 13.7 首次使用

1. 新建笔记本 → 「+ 添加资料」。  
2. 若仅导入 1 条，**自动勾选**该条（可选策略）。

4. 用户一键提炼 → 可选引导「生成文章」，**不阻断**。

**不要**在首次提炼前弹出定位五问。

### 13.8 首版可隐藏的能力（后端保留）

## 附录 C · 与知识库流水线统一（P0 / P1，已定稿）

> **原则**：解析只做一次；风格提炼**消费** RAG/预处理产物，不重复解析原文件；RAG 向量与风格画像**分表分用途**。

### C.1 单一事实源（SSOT）

| 字段 | 用途 |
|------|------|
| `content_text` | 解析后唯一正文 |
| `note_rag_body_hash` | 正文变更指纹（与 RAG 索引一致） |
| `preprocessSummary` / `preprocessTags` | 上传轻量特征 |
| `note_summary` + `note_rag_chunks` | 索引后摘要与分块 |
| `styleSnapshot.noteVersions` | 优先存 `note_rag_body_hash`，无则回退 content hash |

前端 **待更新**：对比 `noteRagBodyHash`（API 下发）与快照，不再仅用前端拼装的 `createdAt`。

### C.2 提炼输入优先级（P1）

对每条勾选 note，`learn` 组装 LLM 输入时：

1. `note_summary`（机器摘要，索引后）  
2. 采样 1～3 条 `note_rag_chunks.chunk_text`（首/中/尾）  
3. `preprocessSummary`（无 1、2 时）  
4. `content_text` 截断（最后回退）

`distillSourceKind`：`rag_indexed` | `preprocess` | `full_body`（仅用于日志/调试）。

### C.3 门控（P0）

可参与提炼当且仅当（勾选 + 非 read_only）：

- `parseOk` / 来源可用（与提问一致），且  
- 具备 `distillBody` 输入：`note_summary` 或 `ragChunkCount > 0` 或正文非空  

**不**在每次保存时自动 `learn`；**可**在 `note_rag_index` 成功后异步写 per-note 轻量 `metadata.styleFeatures`（P2 已做），learn 优先 `features_merge`。

### C.4 实现锚点（研发）

| 模块 | 职责 |
|------|------|
| `note_rag_service.sample_rag_chunk_texts_for_notes` | 采样分块文本 |
| `author_ip_distill_inputs.build_distill_excerpt` | 拼 distill 输入 |
| `author_ip_materials.list_ip_materials` | 挂 `distillBody`、`noteRagBodyHash` |
| `author_ip_distill_llm.build_distill_user_payload` | 读 `distillBody` |
| `list_notes` / notes API | 返回 `noteRagBodyHash`、`noteSummary`、`styleFeaturesReady` |
| `note_style_features` | RAG 成功后异步写 `metadata.styleFeatures`；learn 走 `features_merge` |
| `worker_tasks` `note_style_features` | 后台提取任务（对用户不可见） |

### C.5 明确不做

- 不把风格 traits 写入 `note_rag_chunks` 或共用 embedding 索引。  
- 不因勾选变化自动全文蒸馏。  
- 不用向量检索结果直接替代结构化 `traits` / `tagCloud`。

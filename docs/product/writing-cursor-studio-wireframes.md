### `/studio/[workId]` — Agent-first

```
┌ 任务轨 ──┬─ 主栏 max-w-3xl ────────────────────────────────┐
│ [New Agent]│  对话 · 解释                                  │
│  任务 A    │    用户气泡（可编辑）                          │
│  任务 B ●  │    助手解释（运营/澄清/附言逻辑）               │
│            ├───────────────────────────────────────────────┤
│            │  产物                                         │
│            │    「稿件」标题                                │
│            │    ┌ 标题+正文+话题 一体块 ─────────────┐     │
│            │    └────────────────────────────────────┘     │
│            │    （成稿后温和附言，无小标题）                │
│            │    [改版对比时：采纳所选 / 全部 / 放弃]        │
├────────────┼───────────────────────────────────────────────┤
│            │  [输入框………………………]  [资料▾]  [发送]          │
└────────────┴───────────────────────────────────────────────┘
```

### 主流程（Mermaid）

```mermaid
flowchart LR
  A[输入需求] --> B[对话澄清 ask]

  D --> E[产物区稿件]
  E --> F[postDoneCoach]
```
